原理

像 zip 一样，但为 Bayer 而生

1

拍摄

摄影机始终记录原始未压缩 ARRIRAW，机上不做任何压缩，素材质量零妥协。

2

拷贝时编码

数据从介质拷出的同时，CODEX Platform 在后台自动完成 HDE 编码——无需人工干预，不增加拷卡时间。

3

交付与解码

交付 MXF/HDE（旧机型为 .arx 序列）。使用 ARRI Image SDK 的后期软件透明解码，调用的仍是原始像素值。

HDE 是完全无损的可变码率编码，不是有损压缩——解码还原的文件与原文件逐位一致（bit-exact），画质与元数据分毫不动。

节省的空间

按 HDE 典型体积 ≈ 原始 60% 估算。参考实例：ARRIRAW OpenGate 3.4K 约 996 GB/小时，HDE 后约 584 GB/小时。实际比例随画面内容浮动。

支持范围

什么能用，什么不能

✓ 适用

  • 所有 ARRI ALEXA 与 AMIRA 机型的 ARRIRAW
  • 任意分辨率（为 Bayer 图像优化）
  • Compact Drive、SXR / XR Capture Drive
  • CFast 2.0 介质（7.5.1 起任意品牌读卡器均免费）
  • Silverstack 等工具可直接识别 HDE 卷并照常备份

✕ 不适用

  • ProRes 素材（HDE 仅针对 ARRIRAW）
  • 非 ARRI 机型的 RAW 数据

怎么用

一个勾选框的事

1

装 CODEX Platform

macOS 菜单栏应用，管理 CODEX 介质的同时负责 HDE 编码。

2

勾选 HDE

Preferences 面板里勾一个选项，拷贝时自动编码，CODEX 介质上完全免费。

3

照常工作

已拷出的素材可用 ARRIRAW HDE Transcoder 事后补编码（ALEXA 35 / Xtreme / 265）。
